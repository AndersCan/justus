# Voice guide

How justus talks. Read before drafting or changing any text in `apps/web/src/copy/en.json`.
Only the owner approves text; this file records what they rejected and chose, so drafts start closer.
Sessions append rules from the owner's rewrites (see the `copy-review` skill).

## Rules

- No internal terms. Not "drive key", "share key", "peer", "registry". Use the words in `CONTEXT.md` only where a person would say them.
- Say what the person can do, not how it works. Bad: "Your key is stored locally." Good: "Only your devices can open these photos."
- No hedging or reassurance. Not "Don't worry", "Something may have gone wrong", "Hopefully". State what happened and what to do next.
- Short. One idea per sentence.
