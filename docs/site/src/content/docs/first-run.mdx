title: "First run"
description: "A new person opens Justus for the first time, gives a name and chooses to create or join an album."

import Machine from "@mantaq/inspect/astro/Machine.astro";

| What the person sees                                                   | What they do        | State                             |
| ---------------------------------------------------------------------- | ------------------- | --------------------------------- |
| Intro cards                                                            | Swipes through them | `onboarding.showingIntroCards`    |
| "What should we call you?"                                             | Types a name        | `onboarding.askingForName`        |
| The name is being saved                                                | Waits               | `onboarding.savingName`           |
| "Start sharing", with "Create an album" and "Join with an invite link" | Picks one           | `onboarding.choosingCreateOrJoin` |

**When it goes wrong.** The name could not be saved: the person is back on the name step with the message, still in `onboarding.askingForName`.
