Two people, two phones. Ana wants in; Nils is the Admin.

| Moment                           | Ana sees                                                                                                                                                                                    | Nils (Admin) sees                                                                                              |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Ana opens the link               | Ask to join "&lt;album&gt;"? `joinRequest.decidingToAsk`                                                                                                                                    | Nothing                                                                                                        |
| Ana taps "Ask to join"           | "Asking…" `joinRequest.sendingRequest`                                                                                                                                                      | Nothing                                                                                                        |
| The request is sent              | "Request to join sent to &lt;Admin&gt;. You'll see "&lt;album&gt;" when accepted. &lt;Admin&gt; must be online too: keep Justus open on both phones." `joinRequest.waitingForAdminToAccept` | The request with Accept and Decline `requests.showingRequests`                                                 |
| Ana closes the waiting screen    | Her request stays in "Waiting to join"; when Nils answers, the album opens or the decline shows `joinRequest.noInviteOpen`                                                                  | The request with Accept and Decline                                                                            |
| Ana taps "Cancel request"        | The waiting screen closes and her row leaves "Waiting to join"; the link can be asked through again while it works `joinRequest.noInviteOpen`                                               | The request leaves his list at the next refresh                                                                |
| Nils taps Accept as Viewer       | The album opens, and Ana sees every photo but cannot add any `joinRequest.joinedAlbum`                                                                                                      | `requests.sendingAnswer`                                                                                       |
| Nils taps Accept as Collaborator | The album opens, and Ana can add photos `joinRequest.joinedAlbum`                                                                                                                           | `requests.sendingAnswer`                                                                                       |
| Nils taps Accept all 3           | Nothing yet                                                                                                                                                                                 | A sheet names all three, with Viewers picked; he can pick Collaborators `requests.confirmingAcceptAll`         |
| Nils taps Let them in            | Each lands with the picked role `joinRequest.joinedAlbum`                                                                                                                                   | Each card leaves as its answer goes; one toast says how many are in and as what `requests.sendingAnswersToAll` |
| Nils taps Cancel on the sheet    | Nothing                                                                                                                                                                                     | Nobody is answered; the list reloads `requests.loadingRequests`                                                |
| Nils taps Decline                | "&lt;Admin&gt; didn't accept your request." `joinRequest.declinedByAdmin`                                                                                                                   | `requests.sendingAnswer`                                                                                       |

Not in the app yet: the Admin's side is planned as `membership.requestWaitingForAdmin`, then `membership.addingMember` and `membership.memberOfAlbum` when accepted, or `membership.requestDeclined` when declined.

Albums joined by key before invite links existed show "Waiting for approval" until the Admin opens Justus (`sync.waitingForAdminApproval`).

**When it goes wrong.**

| What went wrong                                           | State                                                       |
| --------------------------------------------------------- | ----------------------------------------------------------- |
| The link is garbled, or too old                           | `joinRequest.showingLinkProblem`, `joinRequest.linkExpired` |
| The request could not be sent                             | Back on `joinRequest.decidingToAsk`                         |
| The link ended while "Ask to join" was open               | `joinRequest.linkExpired`, nothing sent                     |
| The Admin's answer could not be sent; no message is shown | `requests.couldNotSendAnswer`                               |
| The Admin could not add the person                        | `sync.couldNotAddMember`                                    |

**Asking again.** A declined person can ask again with the same or a new link; the Admin answers the new ask. The Admin stops this by turning off the invite link or letting it expire.
