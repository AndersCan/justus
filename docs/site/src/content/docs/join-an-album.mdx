After someone is in, `membership` runs on the Admin's phone for them: Let them add photos, and their phone saying they left (`membership.leftAlbum`).

Albums joined by key before invite links existed show "Waiting for approval" until the Admin opens Justus (`sync.waitingForAdminApproval`).

**When it goes wrong.**

| What went wrong                                           | State                                                       |
| --------------------------------------------------------- | ----------------------------------------------------------- |
| The link is garbled, or too old                           | `joinRequest.showingLinkProblem`, `joinRequest.linkExpired` |
| The request could not be sent                             | Back on `joinRequest.decidingToAsk`                         |
| The link ended while "Ask to join" was open               | `joinRequest.linkExpired`, nothing sent                     |
| The Admin's answer could not be sent; no message is shown | `requests.couldNotSendAnswer`                               |
| The Admin could not add the person                        | `sync.couldNotAddMember`                                    |

**Asking again.** A declined person can ask again with the same or a new link; the Admin answers the new ask. The Admin stops this by turning off the invite link or letting it expire.
